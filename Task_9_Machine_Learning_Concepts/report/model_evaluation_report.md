# Week 9 - House Price Prediction Model Evaluation Report

## 1. Project Overview

This project introduces supervised machine learning by predicting house prices from property characteristics. It uses the actual supplied dataset and compares a manually implemented linear regression model with scikit-learn's Linear Regression implementation.

## 2. Objectives

- Inspect and validate the dataset.
- Prepare numeric and categorical features.
- Encode Location and Property_Type.
- Separate features from the Price target.
- Perform a reproducible train-test split.
- Demonstrate regression from scratch and with scikit-learn.
- Evaluate predictions and explain model coefficients.

## 3. Dataset Description

The dataset contains 300 property records and 8 columns: `Property_ID`, `Area`, `Bedrooms`, `Bathrooms`, `Age`, `Location`, `Property_Type`, and `Price`.

- Target: `Price`
- Numeric predictors: `Area`, `Bedrooms`, `Bathrooms`, `Age`
- Categorical predictors: `Location`, `Property_Type`
- Missing values: 0
- Duplicate rows: 0
- Price range: 3,695,000 to 58,700,000

## 8. Data Cleaning and Preprocessing

The script checks that the CSV exists, is not empty, includes all required columns, has no missing values or duplicates, and contains valid non-negative numeric values. `Location` and `Property_Type` are one-hot encoded with `pd.get_dummies()`. `Property_ID` is excluded because it is an identifier rather than a meaningful predictive feature.

## 9. Feature Selection

The model uses Area, Bedrooms, Bathrooms, Age, Location, and Property_Type. Price is the target. The categorical variables become indicator columns such as `Location_City Center` and `Property_Type_Villa`.

## 10. Train-Test Split

The data is split into 80% training data and 20% testing data using scikit-learn's `train_test_split` with `random_state=42`. The split is deterministic and makes the evaluation reproducible.

## 11. Linear Regression Method

The scratch model adds an intercept column and applies the normal equation:

`beta = (X'X)^-1 X'y`

A Moore-Penrose pseudo-inverse is used for numerical stability. Predictions are generated by multiplying the encoded feature matrix by the learned coefficients. The scikit-learn model uses the same training and testing data for a fair comparison.

## 12. Model Evaluation Metrics

- **MAE:** average absolute prediction error in price units.
- **MSE:** average squared prediction error, which weights larger errors more heavily.
- **R2 Score:** proportion of test-target variation explained by the model.

The script prints metrics calculated from the actual test set for both implementations.

## 13. Results

The final run uses 240 training samples and 60 testing samples. Observed scikit-learn results were:

| Metric   |               Result |
| -------- | -------------------: |
| MAE      |         2,188,736.34 |
| MSE      | 8,454,330,868,276.57 |
| R2 Score |               0.9406 |

The scratch implementation produced MAE `2,188,736.34`, MSE `8,454,330,868,457.58`, and R2 `0.9406`. The small MSE difference is floating-point numerical variation; the two approaches agree on the model behavior.

## 14. Visualization Interpretation

- **Area vs Price:** shows the relationship between property size and price, with colors separating locations.
- **Actual vs Predicted Price:** points closer to the diagonal represent more accurate predictions.
- **Feature Analysis:** compares numeric feature correlations with Price and helps identify which measured variables have stronger linear relationships.

## 15. Important Features

The script prints the scikit-learn coefficient table sorted by absolute coefficient magnitude. The largest observed encoded coefficients were `Location_City Center` at approximately `8,453,714` and `Location_Rural` at approximately `-8,274,417`, followed by `Bedrooms` at approximately `1,585,709`. Coefficients for numeric variables represent the estimated price change for one additional unit while holding the other encoded variables constant. Categorical coefficients represent differences relative to the omitted one-hot category, with all other features held constant.

## 16. Limitations

- The dataset contains only 300 properties.
- A single random split can produce estimates that vary with the split.
- Linear regression assumes an approximately linear relationship.
- The model does not include every real-world pricing factor, such as amenities, neighborhood details, renovations, or market timing.
- Correlation and coefficients do not prove causation.

## 17. Final Conclusion

This project demonstrates a complete beginner-friendly regression workflow: validation, encoding, train-test splitting, scratch mathematics, scikit-learn modeling, evaluation, coefficient interpretation, and visualization. The model results should be used as an educational baseline and improved with more representative data and additional property features.
